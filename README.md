# UEFactory – Download

UEFactory ist ein Automatisierungsspiel aus der Ich-Perspektive, gebaut mit der Unreal Engine 5. Dieses Repo enthält nur die spielbare Windows-Version (kein Quellcode).

## So geht's

1. Öffne https://github.com/marlondcjkdmvjk/UEFactory-Download/releases/latest
2. Lade unter "Assets" die Datei `UEFactory.zip` herunter (ca. 330 MB).
3. Entpacke die ZIP-Datei (Rechtsklick → Alle extrahieren).
4. Starte `UEFactory.exe`.

**Hinweis:** Erscheint die Meldung "Der Computer wurde durch Windows geschützt", klicke auf "Weitere Informationen" → "Trotzdem ausführen". Das Spiel ist nicht signiert.

## Updates

Lade die neue ZIP-Datei und ersetze den alten Ordner. Die Änderungen stehen beim jeweiligen Release.
